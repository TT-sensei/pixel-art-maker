# ピクセルアートメーカー

小学校の図工などで使える、ブラウザ上のピクセルアート制作ツールです。

「まずはマス目を増やし、少しずつ絵をつくる」ことを大切にした、シンプルな作品制作環境です。

## できること

- 16×16からスタートして、マス目を増やしながら制作
- 最大64×64まで対応
- 描く・消す・塗りつぶす・色をひろう
- 左右反転
- パレットから色を選択
- 自分で色をつくる
- 写真を下絵として表示
- 下絵の大きさ・位置・透明度を調整
- 下絵を固定して、その上から描画
- つくった作品をこの端末に保存
- 保存した作品をあとから編集
- PNGとして書き出し

## タブレット向けUI

タブレットPCでの制作を中心に設計しています。

編集画面では、キャンバスを大きく確保し、道具・色・下絵・保存などの操作を右側のパネルにまとめています。

画面サイズや向きを変更した場合も、キャンバスの大きさが自動で調整されます。

## 写真を下絵にする

写真はブラウザ上で下絵として利用できます。

写真そのものを作品データとして保存するのではなく、制作中の下絵として表示します。PNGを書き出す場合も、下絵は含まれません。

## データについて

作品データはブラウザの `localStorage` に保存します。

そのため、基本的にはサーバーやデータベースを使わず、この端末・このブラウザで作品を管理します。

ブラウザのデータを消去した場合などには、保存した作品がなくなることがあります。

## 技術

静的なHTML・CSS・JavaScriptで構成しています。

- `index.html`
- `style.css`
- `app.js`
- `data/examples.js`

外部APIやバックエンドは使用していません。

## 教育での利用

学校の授業や家庭での作品制作など、非営利の教育用途を想定しています。

ピクセルアートを通して、

- 形を単純化する
- 色を選ぶ
- 構図を考える
- 何度も修正する

といった制作の過程を楽しめるようにしています。
